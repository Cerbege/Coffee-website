# ☕ Cerbege Coffee Website

This is a simple coffee shop website built using HTML and CSS.

## 🚀 Features

* Clean and basic layout
* Navigation bar with logo
* Hero section with background image
* Product cards with hover effects
* Simple and responsive structure (basic level)

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📌 Purpose

This project was created to practice basic web design and improve front-end skills.
